# Mis proyectos

- **[🧠 CogniLab](cognilab/)** — App gamificada de estudio para el examen Microsoft AI-103 (quiz, simulacros, boss battles, audio, flashcards, tutor IA). Ver `cognilab/README.md`.
- **[🌟 Aloenglish](aloenglish/)** — App de Ola para aprender inglés (español → inglés, MCER A1–B2): quiz, flashcards con flip 3D, Simulator cronometrado, mini-juegos, racha diaria y un generador de ejercicios con IA (Groq). Frontend estático de un solo archivo + backend Express propio, desplegable en SnapDeploy. Ver `aloenglish/README.md`. Independiente de Alodeutsch.
- **[🧠 BrainBit](frontend/)** — Plataforma unificada de estudio para el examen de aptitud ICT (Informatiker/in EFZ Applikationsentwicklung): 6 categorías de entrenamiento con ejercicios verificados, sincronización de progreso con Supabase y tutor IA con Claude. Documentación completa en `BRAINBIT_MASTER.md`.
